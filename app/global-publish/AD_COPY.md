## 광고 이미지 컨셉

### 옵션 1: Before/After
```
[좌] 3,000만원 / 2년 / 복잡한 과정
     ↓
[우] 200만원 / 4주 / 원스톱
```

### 옵션 2: 비주얼
```
한국어 책 → [AI + 전문가] → 아마존 로고
```

### 옵션 3: 숫자 강조
```
큰 텍스트: "4주 만에 아마존 출간"

```

## 타겟 오디언스 설정

### Facebook/Instagram
```
위치: 대한민국
연령: 30-55세
관심사:
- 글쓰기
- 독서
- 자기계발
- 온라인 강의
- 출판
- 작가
- 전자책
- 아마존

유사 오디언스:
- 출판/글쓰기 관련 페이지 팔로워
- 클래스101, 탈잉 등 강사 플랫폼
```

### 예산 제안
```
테스트 예산: 일 2-3만원 × 14일 = 30-40만원
광고 세트: 3개 (카피 A, B, C)
측정: CTR, 전환율, CPA
```

---

## 성공 기준

```
최소 유의미 데이터:
- 클릭 500회 이상
- 전환 (상담 신청) 10건 이상

목표 지표:
- CTR: 1% 이상
- 전환율: 2% 이상 (클릭 → 신청)
- CPA: 5만원 이하

2주 후 판단:
- 10건 이상 신청 → 서비스 본격 준비
- 5건 미만 → 카피/오퍼 수정 또는 피벗
```
